Multi-Device Compare — Manual Paste

Junos + Arista + Palo Alto, mixed in one run
How to use: click + Add device pair, pick the device type, name it, then paste the before and after CLI output for that device (show route table inet.0 for Junos, show ip bgp detail vrf all for Arista, show routing route for Palo Alto). Add as many pairs as you have devices — mix device types freely. Click Compare once. Results land in separate tabs below, one per device type, each with its own filtering, sorting, and CSV export. Use Save Checkpoint under either box any time you want to archive what's currently pasted there — it downloads a .txt file stamped with the device name and the date/time, so you can keep a running record while you make changes and checks. Nothing here is sent anywhere — everything runs in this browser tab.
